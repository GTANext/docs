XBase 是一个按游戏版本隔离的 **静态库**，为 GTA SA、GTA Vice City 和 GTA III 分别生成 `XBaseSA.lib`、`XBaseVC.lib`、`XBaseIII.lib`。公共 API 形状一致，但每个库只允许使用对应游戏的 plugin-sdk ABI。

当前版本后端状态：

| 库 | 游戏 | 状态 |
|---|---|---|
| `XBaseSA.lib` | GTA San Andreas | 全部 13 个领域已有真实实现；部分特性按能力表报告 Partial |
| `XBaseVC.lib` | GTA Vice City | Player / Ped / Vehicle / Weapon / World / Visual / Teleport / BulletAssist 已有实现；Scene、Camera、Cheats、VehicleEffects、Overlay 未支持 |
| `XBaseIII.lib` | GTA III | Player / Ped / Vehicle / Weapon / World / Visual / Teleport 已有实现；BulletAssist、Scene、Camera、Cheats、VehicleEffects、Overlay 未支持 |

公共符号可链接不等于功能已实现。页面必须使用 `FeatureCapability` 判断细粒度支持；能力返回 `Unsupported` 时，宿主必须禁用对应入口，不能因 XBase 提供兼容桩而启用。

VC/III 库不会复用 SA 地址或 SA 类布局。尚未实现的域通过 `XBase::HasCapability()` 返回 `false`，而不是伪造成功。

<Callout type="info" title="设计哲学">
一行 `#include <XBase/XBase.h>`，通过 `XBase::` 命名空间直接调用全部功能。
</Callout>

## 控制器一览

### 基础设施

| 控制器 | 命名空间 | 职责 |
|---|---|---|
| **Log** | `XBase::Log` | 线程安全日志，文件输出+内存环缓存 |
| **Json** | `XBase::Json` | 递归下降 JSON 解析/序列化 |
| **Config** | `XBase::Config` | JSON 持久化配置，点号嵌套键 |
| **I18n** | `XBase::I18n` | 多语言翻译，目录扫描+fallback 链 |
| **Hooks** | `XBase::Hooks` | kiero D3D9 钩子 + ImGui 集成 |
| **Hotkey** | `XBase::Hotkey` | 按键绑定、Toggle/Hold/Once 模式与持久化 |
| **Platform** | `XBase::Platform` | 文件、模块目录、剪贴板、外部打开、时钟 |
| **Runtime** | `XBase::Runtime` | 当前游戏目标检测与运行环境校验 |
| **Host** | `XBase::Host` | 宿主事件安装、消息提示与版本运行时保护 |

## 版本能力查询

```cpp
#include <XBase/XBase.h>

if (XBase::HasCapability(XBase::FeatureCapability::VehicleBasic)) {
    XBase::Vehicle::Repair();
}
```

能力查询属于当前静态库的编译目标，不是运行时猜测。宿主必须链接与游戏目标对应的库；禁止将 `XBaseSA.lib` 链接到 VC 或 III。

## 宿主生命周期

XBase 作为 XMenu 等宿主的静态库时，由宿主负责驱动生命周期：

```cpp
#include <XBase/XBase.h>

void OnGameInit() {
    XBase::Core::NotifyGameInit();
}

void OnProcess() {
    XBase::Core::Process();
}

// 安装宿主回调；同时启用当前版本的运行时保护
XBase::Host::Install({OnGameInit, OnProcess});

// 显式移交领域；掩码会过滤当前库不支持的领域
XBase::Core::Init(XBase::Core::AllDomains);

// 卸载前恢复状态并清理领域
XBase::Core::Shutdown();
XBase::Host::Shutdown();
```

`Host::Install()` 会同时安装版本相关的运行时保护：VC 增加剧情资源目录纠正与空文件句柄保护，SA/VC 增加剧情期间的对象访问安全门（由 `BulletAssist` 消费）。

## 用法

```cpp
#include <XBase/XBase.h>

XBase::Player::Heal();
XBase::Player::GiveMoney(100000);
XBase::Vehicle::Spawn(411);       // Infernus
XBase::Vehicle::Repair();
XBase::World::SetWeather(0, true); // 锁定晴天
XBase::Weapon::GiveAll();
```

## 构建

- C++20 / Win32 (x86) / MBCS / static runtime
- Premake5 生成 VS2022 解决方案
- `XBaseSA.lib` 使用 `plugin_sa`
- `XBaseVC.lib` 使用 `plugin_vc`，当前未实现域通过能力查询拒绝调用
- `XBaseIII.lib` 使用 `plugin_III`，当前未实现域通过能力查询拒绝调用
- `Setup.bat` 生成项目文件，`Build.bat` 编译三个目标
