`include/XBase/World.h` · `XBase::World`

> World 的游戏对象访问、地址写入、天气锁定、时间锁定和 Pickup 会话由 XBase 管理。XMenu 只转换参数并消费结果；支持情况必须通过 `FeatureCapability` 判断。

## Pickup

```cpp
int SpawnPickup(const Types::PickupOptions& options); // 返回 pickup 句柄，失败返回 -1
bool UpdateLastPickup(const Types::PickupOptions& options); // 在最近一次生成位置重建 pickup
bool RemoveLastPickup();      // 移除最近一次生成的 pickup
bool RemoveTrackedPickups();  // 移除 XBase 创建的全部 pickup
```

```cpp
XBase::World::SpawnPickup({ .modelId = 1240, .type = 3 });
```

XBase 只记录自己创建的 pickup 句柄；`RemoveTrackedPickups()` 不会清空游戏任务 pickup。`WorldPickups` 在 SA 为 `Supported`，VC/III 由 portable 后端实现，报告 `Partial`。


## 生命周期

```cpp
void NotifyGameInit();
void Process();
void Shutdown();
```

`World::Process()` 由 `Core::Process()` 唯一调用，负责天气、时间和运行时状态维护；宿主不得直接调用。`NotifyGameInit()` 丢弃上一局的锁定状态与 pickup 会话；`Shutdown()` 释放天气锁定、恢复时钟与拾取物追踪状态。
