---
title: Overlay
description: 屏幕信息覆盖层，显示 FPS、坐标、血量、护甲、金钱、通缉、时间、室内编号。
---

`include/XBase/Overlay.h` · `XBase::Overlay`

## Init

```cpp
void Init();
```

初始化覆盖层，默认为隐藏状态。

## Process

```cpp
void Process();
```

由 `Core` 领域分发；当前不产生额外每帧工作，保留给后续状态维护。

## Draw

```cpp
void Draw();
```

由宿主在绘制回调中调用，使用游戏字体输出文本，不占用 ImGui 绘制列表。

## SetVisible

```cpp
void SetVisible(bool enable);
```

显示或隐藏覆盖层。

## IsVisible

```cpp
bool IsVisible();
```

返回覆盖层当前是否可见。

## Toggle

```cpp
void Toggle();
```

切换覆盖层的显示与隐藏状态。

## SetPosition

```cpp
void SetPosition(bool topLeft, bool topRight, bool bottomLeft, bool bottomRight);
```

四个角位都会生效：右侧位置按屏幕宽度右对齐，底部位置按行数贴底。四个参数同时为 `false` 时回退到左上角。

## 生命周期

```cpp
void Shutdown();
```

`Shutdown()` 隐藏覆盖层并复位位置状态。SA 实现完整；VC/III 通过 `Capability::Overlay` 报告不支持。
