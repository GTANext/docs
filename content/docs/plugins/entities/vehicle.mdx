`CVehicle.h`

逻辑帧改状态。先 `FindPlayerVehicle` 判空。

## 修复车辆

<Api name="Fix / m_fHealth">
车血约 1000 满，0 炸。逻辑帧。

```cpp
void Fix();
float m_fHealth;
```

```cpp
CVehicle* veh = FindPlayerVehicle();
if (!veh) {
    return;
}
veh->Fix();
veh->m_fHealth = 1000.0f;
```
</Api>

    CVehicle* veh = FindPlayerVehicle();
    if (!veh) {
        return;
    }
    veh->m_fHealth = 1000.0f;
};
