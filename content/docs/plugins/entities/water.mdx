`CWaterLevel.h`

水面高度、波浪、渲染入口。贴水、游泳、船相关判断常用。

## 取水面高度

<Api name="GetWaterLevel / GetWaterLevelNoWaves">
成功写 `*pWaterZ`。

```cpp
static bool GetWaterLevel(/* 重载见头文件：坐标 + out Z + 波浪相关 */);
static bool GetWaterLevelNoWaves(float x, float y, float z, float* pWaterZ);
```

```cpp
float wz = 0.0f;
CVector p = ped->GetPosition();
if (CWaterLevel::GetWaterLevelNoWaves(p.x, p.y, p.z, &wz)) {
    // wz 为无浪水面
}
```
</Api>
