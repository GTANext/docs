`CMenuManager.h` · 全局 `FrontEndMenuManager`

暂停菜单、偏好、是否在前端。逻辑帧里常用来判断「能不能动游戏」。

## 菜单是否打开

<Api name="m_bMenuActive / m_bSaveMenuActive">

```cpp
bool m_bMenuActive;
bool m_bSaveMenuActive;
bool m_bGameNotLoaded;
```

```cpp
if (FrontEndMenuManager.m_bMenuActive) {
    return; // 暂停菜单打开时跳过作弊处理
}
```
</Api>
