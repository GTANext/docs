`CPed.h` · 字段 / 方法以头文件为准

逻辑帧改状态；drawing 只读。

## 改血量与护甲

<Api name="m_fHealth / m_fMaxHealth / m_fArmour">
逻辑帧改。

```cpp
float m_fHealth;
float m_fMaxHealth;
float m_fArmour;
```

```cpp
CPed* ped = FindPlayerPed();
if (!ped) {
    return;
}
ped->m_fHealth = ped->m_fMaxHealth;
ped->m_fArmour = 100.0f;
```
</Api>

## 给武器与切换

<Api name="GiveWeapon / SetCurrentWeapon / ClearWeapons">
逻辑帧。

```cpp
void GiveWeapon(eWeaponType weaponType, unsigned int ammo, bool likeUnused);
void SetCurrentWeapon(int slot);
void SetCurrentWeapon(eWeaponType weaponType);
void ClearWeapons();
void ClearWeapon(eWeaponType weaponType);
CWeapon* GetWeapon(); // 当前槽
```

```cpp
#include "eWeaponType.h"

ped->GiveWeapon(WEAPONTYPE_M4, 999, true);
ped->SetCurrentWeapon(WEAPONTYPE_M4);
// ped->ClearWeapons();
```
</Api>

## 改弹药

<Api name="GrantAmmo / SetAmmo / DoWeHaveWeaponAvailable">

```cpp
void GrantAmmo(eWeaponType weaponType, unsigned int ammo);
void SetAmmo(eWeaponType weaponType, unsigned int ammo);
bool DoWeHaveWeaponAvailable(eWeaponType weaponType);
```

```cpp
if (ped->DoWeHaveWeaponAvailable(WEAPONTYPE_M4)) {
    ped->GrantAmmo(WEAPONTYPE_M4, 100);
}
```
</Api>

## 判断玩家与所在车

<Api name="IsPlayer / IsAlive / m_pVehicle">

```cpp
bool IsPlayer();
bool IsAlive();
CVehicle* m_pVehicle;
// ped flags: bInVehicle
```

```cpp
if (ped->IsPlayer() && ped->IsAlive() && ped->bInVehicle && ped->m_pVehicle) {
    CVehicle* v = ped->m_pVehicle;
}
```
</Api>

## 取坐标

<Api name="GetPosition">
改位置在逻辑帧，别在 drawing。

```cpp
CVector GetPosition();
```

```cpp
CVector pos = ped->GetPosition();
pos.z += 2.0f;
```
</Api>

## 取骨骼位置

<Api name="GetBonePosition / GetTransformedBonePosition">
渲染帧可用；注意 clump 有效。

```cpp
void GetBonePosition(RwV3d& outPosition, unsigned int boneId, bool updateSkinBones);
void GetTransformedBonePosition(RwV3d& inOffsetOutPosn, unsigned int boneId, bool updateSkinBones);
```

```cpp
RwV3d bone{};
ped->GetBonePosition(bone, 5, false); // bone id 见引擎/逆向表
```
</Api>
