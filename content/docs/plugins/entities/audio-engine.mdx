`CAudioEngine.h` · 全局 `AudioEngine`

前端音效、电台、主音量。细粒度 `CAE*` 实体本页不展开。

## 前端音效

<Api name="ReportFrontendAudioEvent">
id / volume / speed。

```cpp
CReference* ReportFrontendAudioEvent(int id, float volume, float speed);
```

```cpp
AudioEngine.ReportFrontendAudioEvent(id, 0.0f, 1.0f);
// id 见游戏音频事件表 / eAudioEvents 相关
```
</Api>

CVector p = ped->GetPosition();
