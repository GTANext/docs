`CPlayerPed.h` · 继承 `CPed`

`FindPlayerPed()` 返回 `CPlayerPed*`。通用 ped API 见 [行人](/docs/plugins/entities/ped)。

## 取通缉

<Api name="GetWanted / SetWantedLevel / CheatWantedLevel">

```cpp
CWanted* GetWanted(); // inline，经 m_pPlayerData
int GetWantedLevel();
void SetWantedLevel(int level);
void SetWantedLevelNoDrop(int level);
void CheatWantedLevel(int level);
void Busted(); // 星清零路径之一
```

```cpp
CPlayerPed* pp = FindPlayerPed();
if (!pp) {
    return;
}
pp->SetWantedLevel(0);
// 或 pp->GetWanted()->SetWantedLevel(0);
```
</Api>
