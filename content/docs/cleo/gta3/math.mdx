## 幂

<Opcode id="0AEE" name="POW" member="Math.Pow">
幂。经典别名 `05F3`。

```text
0AEE POW
in: number, power
out: result
// 经典别名 05F3
```

```lua
local r = pow(2.0, 8.0)
```

```js
const result = Math.pow(number, power)
```
