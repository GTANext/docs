`vc` · 扩展 `CLEO` · 需 CLEO

Lua 里多数可直接 `+ - * /` / 位运算。下列为对应 opcode。经典位运算 `05F9`–`05FF` 与现代名同义时以页内 id 为准。

写法见 [Lua](/docs/cleo/syntax) / [Redux](/docs/cleo/syntax-redux)。

## 整数加

<Opcode id="0A8E" name="INT_ADD">
两整数相加。

```text
0A8E INT_ADD
in: a, b
out: result
```

```lua
local r = intAdd(1, 2)
```

```js
const result = native("INT_ADD", a, b)
```
</Opcode>

## 按位与

<Opcode id="05F9" name="BIT_AND">

```text

out: result
// operator &
```

