## 加载动态库

<Opcode id="0AA2" name="LOAD_DYNAMIC_LIBRARY" member="DynamicLibrary.Load">
把 DLL/模块加载进游戏进程。成功条件为真。

```text
0AA2 LOAD_DYNAMIC_LIBRARY
in: fileName
out: handle
```

```lua
local mod = loadDynamicLibrary("kernel32.dll")
if mod then
end
```

```js
const handle = DynamicLibrary.load(fileName)
```
</Opcode>

## 卸载动态库

<Opcode id="0AA3" name="FREE_DYNAMIC_LIBRARY" member="DynamicLibrary.Free">
卸载模块。

```text
0AA3 FREE_DYNAMIC_LIBRARY
in: self
```

```lua
freeDynamicLibrary(mod)
```

```js
DynamicLibrary.free(self)
```
</Opcode>

## 取导出过程地址

<Opcode id="0AA4" name="GET_DYNAMIC_LIBRARY_PROCEDURE" member="DynamicLibrary.GetProcedure">
取导出地址。条件表示是否找到。

```text
0AA4 GET_DYNAMIC_LIBRARY_PROCEDURE
in: procName, self
out: address
```

```lua
local addr = getDynamicLibraryProcedure("GetTickCount", mod)
if addr then
end
```

```js
const address = DynamicLibrary.getProcedure(procName, self)
```
</Opcode>
