`sa` · 扩展 `CLEO` · 需 CLEO

整数 / 浮点基本运算。Lua 里多数可直接用 `+ - * /`；下列为对应 opcode。

写法见 [Lua](/docs/cleo/syntax) / [Redux](/docs/cleo/syntax-redux)。

## 整数加

<Opcode id="0A8E" name="INT_ADD">
两整数相加。

```text
0A8E INT_ADD
in: a, b
out: result
```

```lua
local r = intAdd(1, 2)
-- 或 r = 1 + 2
```

```js
const result = native("INT_ADD", a, b)
```
</Opcode>
