## 与

<Opcode id="0B10" name="BIT_AND">
按位与。

```text
0B10 BIT_AND
in: a, b
out: result
```

```lua
local r = bitAnd(a, b)
```

```js
const result = native("BIT_AND", a, b)
```
</Opcode>
