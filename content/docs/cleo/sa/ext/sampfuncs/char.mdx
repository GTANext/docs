## 玩家 ID

<Opcode id="0B2B" name="SAMP_GET_PLAYER_ID" member="Char.GetSampId">
返回控制该角色句柄的 SA-MP 玩家 ID；无人控制则返回 -1。

```text
0B2B SAMP_GET_PLAYER_ID
in: self
out: idAsHandle
```

```lua
local idAsHandle = sampGetPlayerId(self)
```

```js
const idAsHandle = Char.getSampId(self)
```
</Opcode>
