## 钩子

<Opcode id="0B34" name="SAMP_HOOK_CHAT_COMMAND_AS_LOCAL" member="SampLocalChatCmd.Hook">
注册客户端侧聊天命令的回调钩子。用在 `if` 里。

```text
0B34 SAMP_HOOK_CHAT_COMMAND_AS_LOCAL
in: chatCommand, callback
```

```lua
if sampHookChatCommandAsLocal(chatCommand, callback) then
end
```

```js
if (SampLocalChatCmd.Hook(chatCommand, callback)) {
}
```
</Opcode>

<Opcode id="0B63" name="SAMP_UNHOOK_LOCAL_CHAT_COMMAND" member="SampLocalChatCmd.Unhook">
移除为 chatCommand 挂上的全部本地回调。用在 `if` 里。

```text
0B63 SAMP_UNHOOK_LOCAL_CHAT_COMMAND
in: chatCommand
```

```lua
if sampUnhookLocalChatCommand(chatCommand) then
end
```

```js
if (SampLocalChatCmd.Unhook(chatCommand)) {
}
```
</Opcode>
