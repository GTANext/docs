## 拾取物 ID

<Opcode id="0B53" name="SAMP_GET_PICKUP_ID" member="Pickup.GetSampId">
按拾取物句柄返回 SA-MP 拾取物 ID。

```text
0B53 SAMP_GET_PICKUP_ID
in: self
out: id
```

```lua
local id = sampGetPickupId(self)
```

```js
const id = Pickup.getSampId(self)
```
</Opcode>
