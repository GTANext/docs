## 物体 ID

<Opcode id="0B52" name="SAMP_GET_OBJECT_ID" member="Object.GetSampId">
按物体句柄返回 SA-MP 物体 ID。

```text
0B52 SAMP_GET_OBJECT_ID
in: self
out: id
```

```lua
local id = sampGetObjectId(self)
```

```js
const id = Object.getSampId(self)
```
