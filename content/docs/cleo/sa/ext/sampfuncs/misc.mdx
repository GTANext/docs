## 图元

<Opcode id="0C3B" name="SF_D3D_BEGIN">
开始指定类型的 D3D 图元绘制。

```text
0C3B SF_D3D_BEGIN
in: primitiveType
```

```lua
sfD3dBegin(primitiveType)
```

```js
native("SF_D3D_BEGIN", primitiveType)
```
</Opcode>

<Opcode id="0C3C" name="SF_D3D_END">
调用 D3D EndScene。

```text
0C3C SF_D3D_END
```

```lua
sfD3dEnd()
```

```js
native("SF_D3D_END")
```
</Opcode>

<Opcode id="0C3D" name="SF_D3D_COLOR">
设置 D3D 当前绘制颜色。

```text
0C3D SF_D3D_COLOR
in: color
```

```lua
sfD3dColor(color)
```

```js
native("SF_D3D_COLOR", color)
```
</Opcode>

<Opcode id="0C3E" name="SF_D3D_VERTEX">
按 `SF_D3D_BEGIN` 指定的图元类型设置顶点。

```text
0C3E SF_D3D_VERTEX
in: startVertex, primitiveCount
```

```lua
sfD3dVertex(startVertex, primitiveCount)
```

```js
native("SF_D3D_VERTEX", startVertex, primitiveCount)
```
</Opcode>


```lua
sfD3dSetTextureCoords(coordX, coordY)
```

```js

```
</Opcode>

<Opcode id="0C40" name="SF_D3D_BIND_TEXTURE">
把纹理绑定到当前 D3D 图元。用在 `if` 里。

```text
0C40 SF_D3D_BIND_TEXTURE
in: textureObjAdress
```

```lua

end
```

```js

}
```
</Opcode>
