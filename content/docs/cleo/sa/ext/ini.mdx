---
title: 配置 IniFile
description: 读写 ini 段与键
---

`sa` · 扩展 `ini` · 需对应 CLEO 扩展

读写 ini 段 / 键。读 / 写失败时条件为假。

写法见 [Lua](/docs/cleo/syntax) / [Redux](/docs/cleo/syntax-redux)。

## 读整数

<Opcode id="0AF0" name="READ_INT_FROM_INI_FILE" member="IniFile.ReadInt">
用在 `if` 里。

```text
0AF0 READ_INT_FROM_INI_FILE
in: path, section, key
out: value
```

```lua
local v = readIntFromIniFile("cleo/mod.ini", "Main", "Count")
if v then
end
```

```js
const value = IniFile.readInt(path, section, key)
```
</Opcode>

## 写整数

<Opcode id="0AF1" name="WRITE_INT_TO_INI_FILE" member="IniFile.WriteInt">
用在 `if` 里。

```text
0AF1 WRITE_INT_TO_INI_FILE
in: value, path, section, key
```

```lua
if writeIntToIniFile(3, "cleo/mod.ini", "Main", "Count") then
end
```

```js
IniFile.writeInt(value, path, section, key)
```
</Opcode>
