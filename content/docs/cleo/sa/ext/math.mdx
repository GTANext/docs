写法见 [Lua](/docs/cleo/syntax) / [Redux](/docs/cleo/syntax-redux)。

## 测位

<Opcode id="2700" name="IS_BIT_SET" member="Math.IsBitSet">
整数第 `bitIndex` 位（0–31）是否为 1。用在 `if` 里。

```text
2700 IS_BIT_SET
in: number, bitIndex
```

```lua
if isBitSet(flags, 3) then
end
```

```js
if (Math.isBitSet(number, bitIndex)) {
}
```
</Opcode>

## 置位

<Opcode id="2701" name="SET_BIT" member="Math.SetBit">
把变量某位置 1。

```text
2701 SET_BIT
in: number, bitIndex
```

```lua
setBit(flags, 3)
```

```js
Math.setBit(number, bitIndex)
```
</Opcode>

## 随机挑整数

<Opcode id="2705" name="PICK_RANDOM_INT" member="Math.RandomPick">
从参数列表里随机挑一个整数。

```text
2705 PICK_RANDOM_INT
in: values...
out: result
```

```lua
local r = pickRandomInt(1, 2, 3, 4)
```

```js
const result = Math.randomPick(...values)
```
</Opcode>
