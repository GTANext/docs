## 加载 / 状态

<Opcode id="0AAC" name="LOAD_AUDIO_STREAM" member="AudioStream.Load">
加载音频文件成流。成功才往下走。用在 `if` 里。

```text
0AAC LOAD_AUDIO_STREAM
in: audioFileName
out: handle
```

```lua
local stream = loadAudioStream("cleo/music.mp3")
if stream then
end
```

```js
const handle = AudioStream.Load(audioFileName)
```
</Opcode>
