`sa` · 扩展 `CLEO+` · 需 CLEO + CLEO+

`SET_SCRIPT_EVENT_*` 的 `add=true` 注册、`false` 注销；`label` 为回调入口。事件里用 `RETURN_SCRIPT_EVENT` 返回。写法见 [Lua](/docs/cleo/syntax) / [Redux](/docs/cleo/syntax-redux)。

## 脚本变量

<Opcode id="0D2E" name="SET_SCRIPT_VAR">
写指定脚本结构体内变量下标。

```text
0D2E SET_SCRIPT_VAR
in: scriptPointer, varIndex, value
```

```lua
setScriptVar(scriptPtr, 0, 42)
```

```js
native("SET_SCRIPT_VAR", scriptPointer, varIndex, value)
```
</Opcode>

<Opcode id="0D2F" name="GET_SCRIPT_VAR">
读脚本结构体内变量。

```text
0D2F GET_SCRIPT_VAR
in: scriptPointer, varIndex
out: result
```

```lua
local v = getScriptVar(scriptPtr, 0)
```

```js
const result = native("GET_SCRIPT_VAR", scriptPointer, varIndex)
```
</Opcode>

## 自定义脚本 / 返回

<Opcode id="0E6F" name="STREAM_CUSTOM_SCRIPT_FROM_LABEL">
从 label 启动自定义脚本，可带参数。

```text
0E6F STREAM_CUSTOM_SCRIPT_FROM_LABEL
in: label, params
```

```lua
streamCustomScriptFromLabel(label, ...)
```

```js
native("STREAM_CUSTOM_SCRIPT_FROM_LABEL", label, params)
```
</Opcode>

<Opcode id="0ED0" name="RETURN_SCRIPT_EVENT">
从脚本事件回调返回。

```text
0ED0 RETURN_SCRIPT_EVENT
```

```lua
returnScriptEvent()
```

```js
native("RETURN_SCRIPT_EVENT")
```
</Opcode>

<Opcode id="0F0A" name="RETURN_TIMES">
连续 `return` 多层 gosub（层数 `numReturns`）。

```text
0F0A RETURN_TIMES
in: numReturns
```

```lua
returnTimes(2)
```

```js
native("RETURN_TIMES", numReturns)
```
</Opcode>
