## 开火类型

<Opcode id="0E26" name="IS_WEAPON_FIRE_TYPE" member="Weapon.IsFireType">
武器是否指定开火类型。用在 `if` 里。

```text
0E26 IS_WEAPON_FIRE_TYPE
in: weaponType, weaponFire
```

```lua
if isWeaponFireType(weaponType, fireType) then
end
```

```js
if (Weapon.isFireType(weaponType, weaponFire)) {
}
```
</Opcode>

## WeaponInfo 句柄

<Opcode id="0E84" name="GET_WEAPONINFO" member="Weapon.GetWeaponInfo">
按武器类型 + 技能取 `WeaponInfo` 句柄。用在 `if` 里。

```text
0E84 GET_WEAPONINFO
in: weaponType, weaponSkill
out: handle
```

```lua
local wi = getWeaponinfo(weaponType, skill)
```

```js
const handle = Weapon.getWeaponInfo(weaponType, weaponSkill)
```
</Opcode>

## 模型

<Opcode id="0E85" name="GET_WEAPONINFO_MODELS" member="WeaponInfo.GetModels">
WeaponInfo 的 model1 / model2。

```text
0E85 GET_WEAPONINFO_MODELS
in: self
out: model1, model2
```

```lua
local m1, m2 = getWeaponinfoModels(wi)
```

```js
const { model1, model2 } = WeaponInfo.getModels(self)
```
