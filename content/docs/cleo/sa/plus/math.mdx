## 1D Perlin

<Opcode id="0E03" name="PERLIN_NOISE" member="Math.PerlinNoise">
1D Perlin simplex 噪声。

```text
0E03 PERLIN_NOISE
in: x
out: result
```

```lua
local n = perlinNoise(t)
```

```js
const result = Math.perlinNoise(x)
```
</Opcode>

## 缓动

<Opcode id="0E1F" name="EASE" member="Math.Ease">
把 `k`（0–1）按 mode / way 做缓动，适合动画。

```text
0E1F EASE
in: k, mode, way
out: result
```

```lua
local e = ease(0.5, mode, way)
```

```js
const result = Math.ease(k, mode, way)
```
</Opcode>

## 百分比随机

<Opcode id="0E4D" name="RANDOM_PERCENT" member="Math.RandomPercent">
约 `percent`% 概率为真。用在 `if` 里。

```text
0E4D RANDOM_PERCENT
in: percent
```

```lua
if randomPercent(25) then
end
```

```js
if (Math.randomPercent(percent)) {
}
```
</Opcode>

## 线性插值

<Opcode id="0EF3" name="LERP">
`a + (b-a)*t`。

```text
0EF3 LERP
in: a, b, t
out: result
```

```lua
local v = lerp(0.0, 1.0, 0.5)
```

```js
const result = native("LERP", a, b, t)
```
</Opcode>
