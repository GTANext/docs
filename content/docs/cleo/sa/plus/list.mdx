`sa` · 扩展 `CLEO+` · 需 CLEO + CLEO+

动态列表（数值 / 字符串）。写法见 [Lua](/docs/cleo/syntax) / [Redux](/docs/cleo/syntax-redux)。

## 生命周期

<Opcode id="0E72" name="CREATE_LIST" member="List.Create">
按 `ListType` 建列表。

```text
0E72 CREATE_LIST
in: type
out: handle
```

```lua
local list = createList(listType)
```

```js
const handle = List.create(type)
```
</Opcode>

<Opcode id="0E73" name="DELETE_LIST" member="List.Delete">
删列表。

```text
0E73 DELETE_LIST
in: self
```

```lua
deleteList(list)
```

```js
List.delete(self)
```
</Opcode>
