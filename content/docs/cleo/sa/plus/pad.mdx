按键「刚按下」检测（本帧边沿）。写法见 [Lua](/docs/cleo/syntax) / [Redux](/docs/cleo/syntax-redux)。

## 键刚按下

<Opcode id="0E3D" name="IS_KEY_JUST_PRESSED" member="Pad.IsKeyJustPressed">
键盘键本帧刚按下（边沿，不是按住）。用在 `if` 里。

```text
0E3D IS_KEY_JUST_PRESSED
in: keyCode
```

```lua
if isKeyJustPressed(keyCode) then
end
```

```js
if (Pad.isKeyJustPressed(keyCode)) {
}
```
</Opcode>

## 未触碰时长

<Opcode id="0F13" name="GET_TIME_NOT_TOUCHING_PAD" member="Pad.GetTimeNotTouching">

```text
0F13 GET_TIME_NOT_TOUCHING_PAD
in: pad
out: timeInMs
```

