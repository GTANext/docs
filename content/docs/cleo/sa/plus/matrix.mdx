`sa` · 扩展 `CLEO+` · 需 CLEO + CLEO+

矩阵、四元数。参数里的 `matrix`/`quat` 多为结构体地址。写法见 [Lua](/docs/cleo/syntax) / [Redux](/docs/cleo/syntax-redux)。

## 矩阵旋转

<Opcode id="0D01" name="ROTATE_MATRIX_ON_AXIS">
绕轴旋转矩阵。

```text
0D01 ROTATE_MATRIX_ON_AXIS
in: matrix, x, y, z, angle, rwCombine
```

```lua
rotateMatrixOnAxis(mat, 0.0, 0.0, 1.0, 45.0, combine)
```

```js
native("ROTATE_MATRIX_ON_AXIS", matrix, x, y, z, angle, rwCombine)
```
</Opcode>

## 局部 → 世界

```text
0D0A GET_OFFSET_FROM_MATRIX_IN_WORLD_COORDS
in: matrix, x, y, z
out: x, y, z
```

```lua
local wx, wy, wz = getOffsetFromMatrixInWorldCoords(mat, 0.0, 1.0, 0.0)
```

```js
const { x, y, z } = native("GET_OFFSET_FROM_MATRIX_IN_WORLD_COORDS", matrix, x, y, z)
```
</Opcode>

## 四元数运算

<Opcode id="0D18" name="ROTATE_QUAT_ON_AXIS">
四元数绕轴旋转。

```text
0D18 ROTATE_QUAT_ON_AXIS
in: quat, x, y, z, angle, rwCombine
```

```lua
rotateQuatOnAxis(quat, 0.0, 1.0, 0.0, 10.0, combine)
```

```js
native("ROTATE_QUAT_ON_AXIS", quat, x, y, z, angle, rwCombine)
```
</Opcode>

<Opcode id="0D19" name="GET_NORMALISED_QUAT">
归一化四元数。

```text
0D19 GET_NORMALISED_QUAT
in: quat
out: quat
```

```lua
local q2 = getNormalisedQuat(quat)
```

```js
const quat = native("GET_NORMALISED_QUAT", quat)
```
</Opcode>

<Opcode id="0D1A" name="MULTIPLY_QUATS">
四元数相乘。

```text
0D1A MULTIPLY_QUATS

out: quatResult
```

```lua
local r = multiplyQuats(q1, q2)
```

```js
const quatResult = native("MULTIPLY_QUATS", quat1, quat2)
```
</Opcode>

```lua
initialiseQuat(quat, 0.0, 0.0, 0.0, 1.0)
```

```js

```
</Opcode>

<Opcode id="0D29" name="GET_QUAT_ELEMENTS">

```text
0D29 GET_QUAT_ELEMENTS

out: x, y, z, real
```

</Opcode>
