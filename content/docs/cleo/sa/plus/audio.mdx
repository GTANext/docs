## SFX 音量

<Opcode id="0E21" name="GET_AUDIO_SFX_VOLUME" member="Audio.GetSfxVolume">
选项里的 SFX 音量。

```text
0E21 GET_AUDIO_SFX_VOLUME
out: volume
```

```lua
local v = getAudioSfxVolume()
```

```js
const volume = Audio.getSfxVolume()
```

## AudioStream 内部

<Opcode id="0E3B" name="GET_AUDIOSTREAM_INTERNAL" member="AudioStream.GetInternal">
取 AudioStream 内部引用，给 bass.dll 一类底层调用。

```text
0E3B GET_AUDIOSTREAM_INTERNAL
in: self
out: address
```

```lua
local bassRef = getAudiostreamInternal(stream)
```

```js
const address = AudioStream.getInternal(self)
```
</Opcode>
