## NOP / 占位

部分环境用空指令垫对齐；无业务效果。具体 opcode 以你装的 CLEO 版本为准。

```lua
-- 一般不需要主动调用
wait(0)
```

```js
// 无统一 Redux 符号；按具体 opcode 用 native("…")
wait(0)
```
