## 创建

<Opcode id="064B" name="CREATE_FX_SYSTEM" member="Particle.Create">
在坐标创建粒子特效。

```text
064B CREATE_FX_SYSTEM
in: name, x, y, z, ignoreBoundingChecks
out: handle
```

```lua
local handle = createFxSystem(name, x, y, z, ignoreBoundingChecks)
```

```js
const handle = Particle.create(name, x, y, z, ignoreBoundingChecks)
```
</Opcode>
