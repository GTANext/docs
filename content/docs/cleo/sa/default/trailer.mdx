## 是否已挂

<Opcode id="07AB" name="IS_TRAILER_ATTACHED_TO_CAB" member="Trailer.IsAttachedToCab">
挂车是否挂在牵引车上。用在 `if` 里。

```text
07AB IS_TRAILER_ATTACHED_TO_CAB
in: self, cab
```

```lua
if isTrailerAttachedToCab(self, cab) then
end
```

```js
if (Trailer.isAttachedToCab(self, cab)) {
}
```
</Opcode>
