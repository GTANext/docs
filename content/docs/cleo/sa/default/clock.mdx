## 取时分

<Opcode id="00BF" name="GET_TIME_OF_DAY" member="Clock.GetTimeOfDay">
取当天时:分（从午夜起算）。

```text
00BF GET_TIME_OF_DAY
out: hours, minutes
```

```lua
local hours, minutes = getTimeOfDay()
```

```js
const { hours, minutes } = Clock.getTimeOfDay()
```
</Opcode>
