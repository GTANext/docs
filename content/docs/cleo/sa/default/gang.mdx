## 帮派三武器

<Opcode id="0237" name="SET_GANG_WEAPONS" member="Gang.SetWeapons">

in: gangId, weaponType1, weaponType2, weaponType3
```

setGangWeapons(gangId, weaponType1, weaponType2, weaponType3)
```

```js
Gang.setWeapons(gangId, weaponType1, weaponType2, weaponType3)
```
