## 添加

<Opcode id="061D" name="ADD_ATTRACTOR" member="Attractor.Add">
添加行人吸引点（位置、朝向、关联序列）。

```text
061D ADD_ATTRACTOR
in: x, y, z, angle, _p5, sequence
out: handle
```

```lua
local handle = addAttractor(x, y, z, angle, _p5, sequence)
```

```js
const handle = Attractor.add(x, y, z, angle, _p5, sequence)
```
</Opcode>

## 清除

<Opcode id="061E" name="CLEAR_ATTRACTOR" member="Attractor.Clear">

```lua
clearAttractor(self)
```

```js
Attractor.clear(self)
```
</Opcode>
