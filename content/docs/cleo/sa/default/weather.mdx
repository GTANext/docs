## 强制天气

<Opcode id="01B5" name="FORCE_WEATHER" member="Weather.Force">
强制天气类型（过渡到该天气）。

```text
01B5 FORCE_WEATHER
in: type
```

```lua
forceWeather(type)
```

```js
Weather.force(type)
```
</Opcode>

