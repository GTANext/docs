## 创建

<Opcode id="0213" name="CREATE_PICKUP" member="Pickup.Create">
按模型与类型创建拾取物。

```text
0213 CREATE_PICKUP
in: modelId, pickupType, x, y, z
out: handle
```

```lua
local handle = createPickup(modelId, pickupType, x, y, z)
```

```js
const handle = Pickup.create(modelId, pickupType, x, y, z)
```
</Opcode>
