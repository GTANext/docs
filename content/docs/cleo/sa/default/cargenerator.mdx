## 创建

<Opcode id="014B" name="CREATE_CAR_GENERATOR" member="CarGenerator.Create">
创建停车生成器（`modelId` -1 用本地 popcycle 随机车）。

```text
014B CREATE_CAR_GENERATOR
in: x, y, z, heading, modelId, primaryColor, secondaryColor, forceSpawn, alarmChance, doorLockChance, minDelay, maxDelay
out: handle
```

```lua
local handle = createCarGenerator(x, y, z, heading, modelId, primaryColor, secondaryColor, forceSpawn, alarmChance, doorLockChance, minDelay, maxDelay)
```

```js
const handle = CarGenerator.create(x, y, z, heading, modelId, primaryColor, secondaryColor, forceSpawn, alarmChance, doorLockChance, minDelay, maxDelay)
```
</Opcode>
