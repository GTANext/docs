## 坐标起火

<Opcode id="02CF" name="START_SCRIPT_FIRE" member="ScriptFire.Start">
在坐标生成脚本火。

```text
02CF START_SCRIPT_FIRE
in: x, y, z, propagation, size
out: handle
```

```lua
local handle = startScriptFire(x, y, z, propagation, size)
```

```js
const handle = ScriptFire.start(x, y, z, propagation, size)
```
</Opcode>
