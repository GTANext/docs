## 给遥控模型

<Opcode id="046E" name="GIVE_REMOTE_CONTROLLED_MODEL_TO_PLAYER" member="Rc.GiveModelToPlayer">

```text

in: handle, x, y, z, angle, modelId
```

```lua
giveRemoteControlledModelToPlayer(handle, x, y, z, angle, modelId)
```

```js

```
</Opcode>

## 取遥控车

<Opcode id="0484" name="GET_REMOTE_CONTROLLED_CAR" member="Rc.GetCar">
取玩家当前遥控车（另见 `00D9` / `03C0` / `0811`）。

```text
0484 GET_REMOTE_CONTROLLED_CAR
in: player
out: car
```

```lua
local car = getRemoteControlledCar(player)
```

```js
const car = Rc.getCar(player)
```
</Opcode>
