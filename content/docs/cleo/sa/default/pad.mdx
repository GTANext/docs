## 键是否按下

<Opcode id="00E1" name="IS_BUTTON_PRESSED" member="Pad.IsButtonPressed">
手柄键是否按下。用在 `if` 里。

```text
00E1 IS_BUTTON_PRESSED
in: pad, buttonId
```

```lua
if isButtonPressed(pad, buttonId) then
end
```

```js
if (Pad.isButtonPressed(pad, buttonId)) {
}
```
</Opcode>
